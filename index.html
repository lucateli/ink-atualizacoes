Publicar uma versão do Ink Leitor pelo celular
DestinoGitHub · main
O arquivo selecionado será publicado em lucateli/ink-atualizacoes/content.js.
Use um token Fine-grained com acesso somente ao repositório ink-atualizacoes e permissão Contents: Read and write. O token fica apenas nesta sessão e não é salvo.
Selecione um arquivo e informe seu token para começar.
Como usar
  1. Crie um token Fine-grained no GitHub com acesso apenas a este repositório.
  2. Informe o token e escolha o novo content.js.
  3. Toque em “Publicar no GitHub” e aguarde a confirmação do commit.
  4. O atualizador do Ink Leitor poderá baixar o arquivo publicado.
