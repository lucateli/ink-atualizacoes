INK ATUALIZADOR ANDROID

Projeto Android nativo (WebView) com seletor de arquivos integrado.
A interface usa a API do GitHub para publicar content.js em:
lucateli/ink-atualizacoes / branch main.

GERAR APK PELO GITHUB ACTIONS
1. Envie todo o conteúdo deste projeto para um repositório GitHub.
2. Abra a aba Actions.
3. Execute "Build Ink Atualizador APK" (Run workflow).
4. Baixe o artefato "Ink-Atualizador-APK".
5. Dentro dele estará app-debug.apk, instalável no Android.

GERAR LOCALMENTE
Requer Android SDK (API 35), Java 17 e Gradle 8.9:
  gradle assembleDebug

SEGURANÇA
O token do GitHub é digitado no app e usado em memória na sessão; não está
embutido no APK. Crie Fine-grained PAT limitado ao repositório
lucateli/ink-atualizacoes com Contents: Read and write.
Não compartilhe o token. Revogue-o se suspeitar que foi exposto.

OBSERVAÇÃO
O app Android foi preparado, mas este ambiente não possui Android SDK/Gradle,
então não foi possível compilar um APK binário aqui.
